# 03 · Spacing

An 8-point scale for margins, padding and fixed element heights. The token key is the multiplier of 8px.

| Token | px | CSS |
|---|---|---|
| 0.25 | 2 | `--space-0_25` |
| 0.5 | 4 | `--space-0_5` |
| 1 | 8 | `--space-1` |
| 2 | 16 | `--space-2` |
| 3 | 24 | `--space-3` |
| 4 | 32 | `--space-4` |
| 5 | 40 | `--space-5` |
| 6 | 48 | `--space-6` |
| 7 | 56 | `--space-7` |
| 8 | 64 | `--space-8` |
| 9 | 72 | `--space-9` |
| 10 | 80 | `--space-10` |
| 11 | 88 | `--space-11` |
| 12 | 96 | `--space-12` |

Use 2px and 4px only for hairlines and icon nudges. Component padding usually lives between 1 and 3; section spacing between 6 and 12.
