# 05 · Layout

**Grid:** 12 columns, 24px gutter, on desktop (800px and up, from the original guide).

**Breakpoints** (`--breakpoint-*` are informational; use the px values in media queries):

| Token | px | Meaning |
|---|---|---|
| sm | 480 | Phones |
| md | 800 | The desktop grid starts here; display sizes drop below it |
| lg | 1200 | Wide desktop |
| xl | 1600 | Very wide |

For the map app, the panel is a side sheet at `md` and above and a bottom sheet below it.
