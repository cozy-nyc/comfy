# 07 · Iconography

**Logo.** The cozy cube, in `assets/logo/cube-{white,pink,hot,blue,deep}.svg` (60×60 viewBox). Never recolor it by hand; add a new variant file.

**Icon set: not started.** The plan, following the Caldera approach:

- 24×24 grid, 2px stroke or filled, curves that match the cube's rounded corners.
- Files in `assets/icons/<name>.svg`, `currentColor` fills so CSS sets the color.
- First batch for the map app: place/pin, music/sound on/off, comment, walk, locate-me, close, search, share, chevrons, time/clock, heat/flame, subway.
- Export from the Figma "Iconography" page once it exists.
